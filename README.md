# NY → SF Grand Tour

An interactive road trip slideshow — a self-contained HTML swipe deck covering the route from New York to San Francisco, with stops, dates, drive times, stay notes, costs, and links.

**Live site:** https://bhornberg.github.io/Roadtrip/

- `index.html` — the deck served by GitHub Pages
- `roadtrip-grand-tour-deck.html` — same file under its original name

Deployed automatically from `main` via GitHub Actions (`.github/workflows/pages.yml`).
